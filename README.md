# Unburdened

A lightweight, iPhone-first weight-progress app.

## GitHub Pages
Upload **all files and folders in this package to the repository root**.

Then:
1. Commit to `main`.
2. Open **Settings → Pages**.
3. Deploy from the repository using GitHub Pages / GitHub Actions as you normally do.
4. Open the site in Safari on iPhone and use **Add to Home Screen**.

## Tracking
- Weight: weekly
- Waist: optional, every 2 weeks
- Progress photos: about every 4 weeks
- Checkpoints: 2.5 kg
- Start: 126 kg
- Goal: 70 kg

Data is stored locally on the device. Use **More → Export Save** for a JSON backup.
